# SecureMsg — راهنمای کاربر

پیام‌رسان رمزنگاری‌شده‌ی سرتاسری که داخل cmd (ویندوز) یا ترموکس (اندروید) اجرا می‌شه.
پسورد تو هیچ‌وقت به سرور نمی‌رسه و پیام‌هات فقط روی دستگاه خودت ذخیره می‌شن.

آدرس سرور: `securemsg.dr-febby-minecraft.workers.dev`

---

## ویندوز (۱۰ و ۱۱)

### مرحله ۱: پیش‌نیاز (Node.js)
لازم نیست دستی نصبش کنی، مرحله‌ی بعد خودش نصبش می‌کنه.
اگه می‌خوای دستی نصب کنی:
1. برو به https://nodejs.org
2. دکمه‌ی **LTS** رو دانلود و نصب کن (همه‌ی گزینه‌ها رو Next بزن).
3. cmd جدید باز کن و بزن `node -v`. باید عدد ۲۲ یا بالاتر نشون بده.

### مرحله ۲: نصب برنامه
cmd رو باز کن (کلید Windows رو بزن، بنویس `cmd` و Enter) و این خط رو کامل کپی کن:

```
curl -sLo %TEMP%\sm.bat https://securemsg.dr-febby-minecraft.workers.dev/start.bat && %TEMP%\sm.bat securemsg.dr-febby-minecraft.workers.dev
```

- اگه Node.js نصب نبود، خودش نصبش می‌کنه. بعدش **cmd رو ببند، یه cmd جدید باز کن و همین خط رو دوباره بزن**.
- می‌پرسه `[1] Login [2] Create account`. اولین بار `2` رو بزن.
- یوزرنیم (انگلیسی، ۳ تا ۲۰ کاراکتر، فقط حروف کوچک و عدد و `_`) و پسورد (حداقل ۱۰ کاراکتر) بساز.

### مرحله ۳: دفعه‌های بعد
```
node %USERPROFILE%\.securemsg\client.js
```
گزینه‌ی `1` (Login) رو بزن و وارد شو.

### میانبر روی دسکتاپ
یه بار تو cmd این رو بزن:
```
echo @node "%USERPROFILE%\.securemsg\client.js" > "%USERPROFILE%\Desktop\SecureMsg.bat"
```
از این به بعد روی فایل `SecureMsg.bat` تو دسکتاپ دوبار کلیک کن.

### میانبر با دستور `sm` تو cmd
یه بار بزن:
```
echo @node "%USERPROFILE%\.securemsg\client.js" %* > "%WINDIR%\sm.bat"
```
اگه ارور Access Denied گرفتی، cmd رو **Run as administrator** باز کن و دوباره بزن. بعدش تو هر cmd فقط بنویس `sm`.

## ترموکس (اندروید)

### مرحله ۱: نصب خود ترموکس
- ترموکس رو از **F-Droid** (https://f-droid.org) یا صفحه‌ی GitHub خودش دانلود کن.
- نسخه‌ی Google Play قدیمیه و درست کار نمی‌کنه.

### مرحله ۲: پیش‌نیازها
داخل ترموکس بزن:
```
pkg update -y && pkg install -y nodejs curl
```
با `node -v` چک کن که عدد ۲۲ یا بالاتر باشه. اگه کمتر بود، `pkg upgrade -y` رو بزن.

### مرحله ۳: نصب برنامه
```
mkdir -p ~/.securemsg
curl -sLo ~/.securemsg/client.js https://securemsg.dr-febby-minecraft.workers.dev/client.js
```

### مرحله ۴: ساخت دستور `sm`
```
cat > $PREFIX/bin/sm << 'EOF'
#!/data/data/com.termux/files/usr/bin/sh
exec node "$HOME/.securemsg/client.js" "$@"
EOF
chmod +x $PREFIX/bin/sm
hash -r
```

### مرحله ۵: اجرا
فقط بنویس:
```
sm
```
اولین بار `2` (ساخت حساب) و دفعه‌های بعد `1` (ورود). اولین بار آدرس سرور رو می‌پرسه، این رو بنویس:
```
wss://securemsg.dr-febby-minecraft.workers.dev
```

اگه به‌جای برنامه، لیستی با `list-disks` اومد، یعنی دستور سیستمی اندروید اجرا شده. `which sm` رو بزن، باید مسیرش `.../usr/bin/sm` باشه.

## استفاده از برنامه

بعد از ورود، صندوق پیام‌ها رو می‌بینی (لیست گفتگوها با تعداد پیام‌های جدید).

| دستور | کار |
|---|---|
| `msg <user> <text>` | ارسال یه پیام. اگه کاربر وجود نداشته باشه، خطا می‌ده |
| `chat <user یا شماره>` | باز کردن گفتگو. داخلش هر چی بنویسی ارسال می‌شه |
| `/back` | (داخل گفتگو) برگشت به صندوق پیام‌ها |
| `list` | نمایش صندوق پیام‌ها |
| `fp [user]` | نمایش اثر انگشت کلید برای تأیید هویت |
| `trust <user>` | قبول کردن کلید جدید یه مخاطب |
| `quit` | خروج |

مثال: `msg ali سلام` یا `chat ali`

اگه طرف مقابل آفلاین باشه، پیام رمزشده تا ۳۰ روز تو سرور می‌مونه و وقتی آنلاین شد بهش می‌رسه.

## نکته‌های مهم

- **پسورد رو فراموش نکن.** کلیدها و پیام‌هات فقط تو پوشه‌ی `.securemsg` روی همین دستگاه هستن و راه بازیابی وجود نداره.
- اگه پوشه‌ی `.securemsg` پاک بشه یا دستگاه عوض بشه، حساب قبلی از دست می‌ره.
- هر دستگاه حساب جدا داره. حساب یه دستگاه به دستگاه دیگه منتقل نمی‌شه.
- اگه هشدار «کلید مخاطب عوض شد» دیدی، قبل از `trust` با `fp` از خودش تأیید بگیر، چون ممکنه حمله باشه.
- cmd ویندوز فارسی رو درست نشون نمی‌ده، برای همین رابط برنامه انگلیسیه.

## مشکلات رایج

| مشکل | راه‌حل |
|---|---|
| `node is not recognized` | Node.js نصب نشده یا cmd رو بعد از نصب نبستی. cmd رو ببند و دوباره باز کن |
| ارور `node:sqlite` | نسخه‌ی Node قدیمیه. Node.js LTS جدید نصب کن |
| `That username is already taken` | یوزرنیم دیگه‌ای انتخاب کن |
| `Wrong password` | پسورد اشتباهه. اگه یادت نیست، راه بازیابی نیست |
| `Could not reach the server` | اینترنتت رو چک کن و آدرس سرور رو دوباره بررسی کن |
| `Authentication failed` | حساب تو این دستگاه با حساب سرور نمی‌خونه. با یه یوزرنیم دیگه ثبت‌نام کن |
